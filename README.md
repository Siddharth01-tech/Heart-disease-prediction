# Heart-Disease-Prediction
## Project Overview

This project predicts whether a patient has heart disease based on medical attributes using Machine Learning. The objective is to build a classification model that can assist in the early detection of heart disease.

## problem Statement

Analyze the provided Heart Disease dataset, perform Exploratory Data Analysis (EDA), preprocess the data, and develop a Machine Learning model to predict the presence of heart disease.
